# منصة اليمن التعليمية بالذكاء الاصطناعي

بوت تيليجرام تعليمي لطلاب اليمن. المستودع عام ويحتوي على الكود فقط؛ لا تُحفظ فيه بيانات الطلاب أو أسرار التشغيل.

## الملفات

- `bot.py`: منطق البوت والتكاملات.
- `content.py`: النصوص والتعليمات والمصادر التعليمية.
- `requirements.txt`: اعتماديات Python.
- `.github/workflows/ci.yml`: فحص الاعتماديات وصياغة Python.
- `.github/workflows/bot.yml`: تشغيل يدوي عبر `workflow_dispatch`، ويمكن استدعاؤه من cron-job.org.

## الخصوصية والذاكرة

بيانات المستخدمين والتقدم والمحادثات والإعدادات وسجل التدقيق وموضع تحديثات تيليجرام تُحفظ في ذاكرة العملية فقط. لا يستخدم البوت GitHub Contents API ولا يكتب ملفات JSON إلى المستودع. تُمسح هذه الحالة عند انتهاء التشغيل أو إعادة تشغيله، بما في ذلك إعدادات الإدارة التي تُعدّل أثناء الجلسة.

## إعداد أسرار GitHub Actions

أضف الأسرار التالية إلى إعدادات المستودع قبل تشغيل `Run Telegram Bot`:

- `TELEGRAM_BOT_TOKEN`
- `GEMINI_API_KEYS`
- `GROQ_API_KEY`
- `WOLFRAM_APPID` إذا أردت تفعيل حل المسائل عبر Wolfram|Alpha

لا يحتاج البوت إلى `GITHUB_TOKEN` ولا إلى صلاحية كتابة محتويات المستودع. Workflow يستخدم `contents: read` لتمكين checkout فقط.

## التشغيل

يمكن تشغيل البوت يدوياً من تبويب Actions عبر workflow `Run Telegram Bot`، أو استدعاء `workflow_dispatch` من cron-job.org. وظيفة GitHub Actions محددة بمهلة 355 دقيقة؛ هذا ليس ضمان تشغيل بلا انقطاع، وقد تُفقد الحالة الموجودة في الذاكرة عند كل إعادة تشغيل.

## فحص الكود محلياً

```bash
python -m py_compile bot.py content.py
```

لم يُرفق ملف ترخيص في هذه النسخة؛ راجع حقوق إعادة الاستخدام قبل التوزيع.
