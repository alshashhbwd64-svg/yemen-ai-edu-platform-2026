# منصة اليمن التعليمية بالذكاء الاصطناعي

هذا المستودع العام يحتوي على ملفات الكود فقط. أُنشئ بتاريخ Git جديد ومنقّى؛ لا يتضمن ملفات بيانات الطلاب أو سجل Git القديم.

## الملفات

- `bot.py`: منطق البوت والتكاملات.
- `content.py`: النصوص والتعليمات والمصادر التعليمية.
- `requirements.txt`: اعتماديات Python.
- `.github/workflows/ci.yml`: فحص الاعتماديات وصياغة Python فقط؛ لا يشغّل البوت.

## تنبيه الخصوصية والتشغيل

النسخة الحالية من `bot.py` ما زالت تستخدم GitHub Contents API لقراءة/حفظ ملفات الحالة عند تزويدها بإعدادات GitHub المناسبة. لا تشغّل البوت من هذا المستودع العام ولا تمنحه رمز كتابة إلى هذا المستودع؛ فقد يؤدي ذلك إلى حفظ بيانات الطلاب فيه. قبل تشغيل نسخة إنتاجية، انقل الحالة إلى قاعدة بيانات خاصة وراجع طريقة تحميل الإعدادات، ثم أضف الأسرار إلى بيئة الاستضافة الآمنة.

ملفات الأسرار وبيانات التشغيل مثل `users.json` و`progress.json` و`audit_log.json` و`config.json` و`offset.json` مستبعدة عمداً. كما أن أسرار GitHub Actions لا تنتقل تلقائياً بين المستودعات. فحص CI هنا لا يختبر الاتصال الفعلي بتيليجرام أو مزودي الذكاء الاصطناعي.

## فحص الكود

يمكن تشغيل فحص الصياغة محلياً بالأمر:

```bash
python -m py_compile bot.py content.py
```

## الترخيص

راجع الترخيص قبل إعادة الاستخدام أو التوزيع؛ لم يُرفق ملف ترخيص في هذه النسخة.
